<img width="1109" height="666" alt="SelecionandoContato" src="https://github.com/user-attachments/assets/1582c31c-52df-42a7-8ed8-52fb0a62e650" />

Projeto desenvolvido em Java com interface gráfica utilizando Swing,
integrado ao banco de dados MySQL.

## 🚀 Sobre o projeto

Este projeto começou como uma agenda de contatos simples em Java,
utilizando ArrayList.

Durante o desenvolvimento, o projeto foi evoluído para uma aplicação
com interface gráfica e persistência de dados em MySQL.

## 🤖 Uso de Inteligência Artificial

Durante o desenvolvimento deste projeto, utilizei ferramentas de
Inteligência Artificial como apoio ao aprendizado e desenvolvimento.

A IA foi utilizada principalmente para:

- esclarecer dúvidas sobre Java;
- entender conceitos como JDBC e PreparedStatement;
- auxiliar na identificação e correção de erros;
- receber orientações durante a implementação;
- entender o funcionamento de cada parte do código.

O projeto foi desenvolvido de forma prática, com implementação,
testes e validação das funcionalidades realizadas durante o processo
de aprendizado.

O objetivo principal deste projeto foi aprender como integrar uma
aplicação Java a um banco de dados MySQL e desenvolver uma aplicação
CRUD com interface gráfica.
